## Screenshot Guidelines

- **Resolution**: 1280x720 or higher recommended
- **Format**: PNG for best quality
- **Content**: Use sample photos with varied metadata for realistic examples
- **Annotations**: Consider adding red circles/arrows to highlight UI elements

## How to Take Screenshots

### Windows
- Press `Win + Shift + S` for Snipping Tool
- Or use `Alt + PrtScn` for active window

### macOS
- Press `Cmd + Shift + 4` for selection
- Press `Cmd + Shift + 4` then `Space` for window

### Linux
- Use `gnome-screenshot` or `scrot`
- Or press `PrtScn` key
