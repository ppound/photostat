# Screenshots Needed

This document lists all screenshots referenced in the documentation. Use Windows Snipping Tool (`Win+Shift+S`) to capture these and save them in the `docs/images/` folder.

## How to Capture Screenshots

### Windows (Recommended)
1. Press `Win + Shift + S`
2. Select the area to capture
3. Open Paint or any image editor
4. Paste (`Ctrl + V`)
5. Save as PNG in `docs/images/`

### Alternative: Full Window
1. Click on the PhotoVault window
2. Press `Alt + Print Screen`
3. Paste into Paint
4. Save as PNG

## Screenshot Specifications

- **Format**: PNG (preferred) or JPEG
- **Width**: 800-1200 pixels recommended
- **Quality**: Clear, readable text
- **Content**: Remove any sensitive file paths or personal information
